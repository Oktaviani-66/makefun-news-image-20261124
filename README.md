A one-day newspaper front page lit in black ink and burnt orange on ivory:
36 dated stories across 9 honestly counted regions for Tuesday
24 November 2026. The full-width lead is the sinking of the Russian
corvette Merkury off Benghazi by 7 Ukrainian sea drones; beside it,
Nvidia's board bringing back Jensen Huang (shares +31%) and COP31
ending with no deal for the first time since 2000. Below: the Kyiv
strikes (15 killed, 11 in Dymer), the Sparta II tow, Iran sanctions,
Gaza, Yemen, gold at $3,588, Bitcoin at $61,284, GTA VI's $3.8bn first
day, the 258-173 House result and the drawn Wellington Test — plus a
verified timeline, a dotted world map whose pins match the story
numbers, an ALSO ON brief column, and a DATE CHECK box naming the
older stories that are not today's news.

## How to run

`main.py` (Python 3, standard library only) copies `entry.png` to the
output directory and verifies it is exactly 1024x1024 and at most 1 MiB:

```
MAKEFUN_OUTPUT_DIR=out python3 main.py
```

`compose_lantern.py` is the build-time renderer that drew `entry.png`
(Pillow, run locally while building; it is not run by the entry program).
