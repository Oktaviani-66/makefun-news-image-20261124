## How to run

`main.py` (Python 3, standard library only) copies `entry.png` to the output
directory and verifies it is exactly 1024×1024 and at most 1 MiB:

```
MAKEFUN_OUTPUT_DIR=out python3 main.py
```

`compose_harbour.py` is the build-time renderer that drew `entry.png`
(Pillow, run locally while building; it is not run by the entry program).
